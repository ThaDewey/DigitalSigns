# Example schedule for Dropbox hosting
#
# Rename this to schedule.txt if you are using Dropbox instead of GitHub, and
# set  #define CONTENT_BASE ""  in config.h.
#
# The difference from the GitHub version is that each line carries the whole
# link instead of just a filename. Dropbox gives every single file its own
# random address, so there is no shared folder path to build on - you have to
# paste each one in full.
#
# To get a link: right-click the file in Dropbox -> Copy link. That gives you
# something ending in "&dl=0". Change that 0 to a 1. Without it you get the
# Dropbox preview web page rather than the image, and the sign will tell you
# "That file is not a BMP".
#
# Check every link by pasting it into a browser first. It should download or
# show the image immediately, with no Dropbox page around it.
#
# The links below are made up - replace them with your own.
