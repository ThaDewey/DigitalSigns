# Door sign schedule

# One rule per line:   DAYS  START-END  filename.bmp
#
# DAYS     MON TUE WED THU FRI SAT SUN, a comma-separated list like MON,WED,FRI,
#          or one of the shortcuts WEEKDAY, WEEKEND, ALL
# START-END  24-hour clock. A range may run past midnight (17:00-08:00).
#            Use 00:00-24:00 to mean the whole day.
# filename   a 1-bit 800x480 BMP sitting in this same folder
#
# The FIRST line that matches wins, so put the specific rules at the top and
# leave the catch-all at the bottom. Anything after a # is a comment.
#
# The sign re-reads this file every time it wakes, so editing it here and
# pushing to GitHub is all it takes - the board never needs re-flashing.
